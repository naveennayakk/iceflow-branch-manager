# Daily Operations Guide

## Sub-branch morning

1. Sign in with branch username/password  
2. Open **Employees**  
3. Select employee → **Open Daily Session**  
4. Enter stock-out quantities (Enter moves to next row)  
5. Save Morning Stock-Out  
6. Or ask Ashok: turn Voice Mode ON → `Ashok Sai cups stock-out 5` → Confirm/Save  

## Sub-branch evening

1. Open same employee session  
2. Enter stock-in (cannot exceed stock-out)  
3. Optionally enter damaged qty  
4. Enter PhonePe + Cash  
5. Review Total Bill, Cash to collect, New Outstanding  
6. Save Draft or Finalize Day  
7. Generate Bill PDF / WhatsApp / SMS summary  

## Main Branch daily

1. Review dashboard alerts (requests, damage, fraud, low stock)  
2. Approve stock requests → create/pack/send dispatches  
3. Approve damage write-offs when valid  
4. Check audit + profit reports across branches  
5. Create scheduled backups  

## Important rules

- Stock-in never greater than stock-out  
- Rate changes never rewrite past finalized bills  
- Profit is in Payments/Reports, not Sub home dashboard  
- Financial records are soft-deleted with reason
