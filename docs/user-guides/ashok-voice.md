# Ashok Voice Guide

## Activation

1. Click the floating **Ashok** button (bottom-right)  
2. Toggle **Voice Mode: ON** (default is OFF)  
3. System shows: “Voice mode is active. Say ‘Ashok’ before commands.”  

## Wake word

Ashok ignores speech until it hears **Ashok** (supported scripts include English and Indic forms).

## Safe workflow

1. Command heard → **draft only**  
2. Ashok reads aloud + shows preview  
3. User says/clicks **Save**, **Edit**, or **Cancel**  
4. Multiple drafts can accumulate for one employee  
5. Final save creates stock movements + audit logs  

## Examples

- `Ashok Sai cups stock-in 10`  
- `Ashok read today’s stock`  
- `Ashok show Sai outstanding`  
- `Ashok complete Sai` → then `Save`  

## Security

- Sensitive actions need on-screen confirmation / PIN  
- Sub-branch Ashok cannot reveal other branch data  
- Voice enrollment is optional extra safety (stored on user profile)
